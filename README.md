### Привет 👋

Frontend-разработчик, которого затянуло в AI-агентов. Делаю интерфейсы, которыми приятно пользоваться, — а последнее время ещё и агентов, которые за этими интерфейсами живут: планируют, зовут инструменты, проверяют друг друга.

- **Frontend** — React / Next.js / TypeScript, дизайн-системы, анимации и микровзаимодействия
- **AI-агенты** — мультиагентные системы, tool-use, MCP-серверы, Claude / OpenAI API
- **Боты** — Telegram-боты на Python и Node.js
- **Сейчас** — копаю, как делать нормальный UI для агентов: стриминг, human-in-the-loop, прозрачность действий

<summary>Как устроена эта страница</summary>
<br>

Всё, что здесь двигается, — обычные SVG с SMIL-анимациями, без единого внешнего сервиса: ничего не отваливается из-за рейт-лимитов и не тормозит. Картинки генерирует [`scripts/build.mjs`](scripts/build.mjs) (`npm run build`), змейку раз в 12 часов перерисовывает [GitHub Action](.github/workflows/snake.yml). Иконки — [Simple Icons](https://simpleicons.org) и [Lucide](https://lucide.dev).
